🔄 Fluxo de Navegação

1️⃣ Primeira Visita

Usuário acessa qualquer página → Script detecta → Redireciona para landing.html

2️⃣ Landing Page

Landing page exibida com animação fade-in → Usuário escolhe um card

3️⃣ Redirecionamento

Script marca sessionStorage → Redireciona para página selecionada

4️⃣ Próximas Visitas

Mesma sessão → Acessa páginas direto (sem landing) | Nova sessão → Landing novamente
