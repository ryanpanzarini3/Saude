🧪 Instruções de Teste

Teste 1: Primeira Visita

✓ Esperado: Landing page aparece automaticamente
Como testar: Limpar sessionStorage → Acessar index.html ou qualquer página

Teste 2: Clique nos Cards

✓ Esperado: Cada card redireciona para a página correta
Como testar: Clicar em cada card da landing page

Teste 3: Navegação por Teclado

✓ Esperado: Tab navega entre cards, Enter ativa
Como testar: Pressionar Tab para navegar, Enter para ativar card

Teste 4: Responsividade

✓ Esperado: Layout se adapta para mobile (1 coluna)
Como testar: Redimensionar janela ou usar DevTools modo responsivo

Teste 5: Modo Escuro

✓ Esperado: Landing page se adapta ao modo escuro
Como testar: DevTools → Rendering → Emulate CSS media feature prefers-color-scheme
